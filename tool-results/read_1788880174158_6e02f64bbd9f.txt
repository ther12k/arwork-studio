     6→Architecture decisions:
     7→- Python FastAPI studio backend runs as a mini-service on port **8765** (`mini-services/color-duel-studio`).
     8→  The Next.js frontend (port 3000) reaches it via the Caddy gateway using `?XTransformPort=8765`
     9→  and the required `X-Studio-Request: 1` header on POSTs.
    10→- Frontend = single Next.js page at `/` (React + shadcn/ui), replicating and upgrading the vanilla
    11→  studio (project list, reference/master upload, brief, chat, build settings, tabs Master/Vector/
    12→  Numbered/Play test/Edit regions, inspector, QA panel, revisions, export links).
    13→- `detailed-board.mjs` (VectorBoard) is ported to TypeScript at `src/lib/detailed-board.ts` and
    14→  wrapped in a React component; the play test uses real geometry (regions/palette/paint JSON).
    15→- AI features are bridged to z-ai-web-dev-sdk (LLM + image generation) through a bun mini-service
    16→  on port **8787** (`mini-services/ai-bridge`) exposing an OpenAI-compatible endpoint layer; the
    17→  Python `Provider` is patched with an `AI_BASE_URL` override so no external OpenAI key is needed.
