# Provenance and usage notes

The source example in `examples/treehouse-source.png` is an earlier AI-generated treehouse illustration from this conversation, not an extracted competitor screenshot. The generated geometry is a deterministic compilation of that sample. It is included to demonstrate the pipeline, not as a legally cleared commercial art library.

The studio does not ship competitor screenshots as source artwork. It accepts user-owned/licensed masters and references, records source hashes and permission attestations, and separates inspiration discussion from direct image editing. These measures do not establish copyright clearance, exclusivity or ownership of an output. Review each source and each final image before publication.

Do not mistake the old promotional before/after PNG pairs for aligned source/region data. This system derives its before/after states from one master and one region partition. All labels are generated from metadata, not read from a prior PNG.

New studio source files were created for this delivery. The detailed-board adapter is adapted from the previous generated asset package in this conversation. Dependencies retain their own licenses; see installed package metadata. No third-party font files, external artwork library or model weights are bundled. Fonts are system fonts.
